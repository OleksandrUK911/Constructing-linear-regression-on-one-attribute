# 📊 Лінійна регресія для прогнозування медичних витрат

## 📖 Опис проєкту

Цей проєкт присвячений аналізу залежності медичних витрат (`charges`) від віку пацієнта (`age`) з використанням методів лінійної регресії. Аналіз проводиться окремо для двох груп: **некурців** та **курців**.

Датасет: `medical-charges.csv` — містить інформацію про медичні витрати пацієнтів з різними характеристиками.

---

## 🎯 Завдання

### 🔹 Завдання 1: Лінійна регресія для некурців

**Мета:** Знайти найкращу лінію для прогнозу медичних витрат за віком для некурців.

**Реалізовано три методи:**

#### 1️⃣ Метод найменших квадратів (МНК)
- Реалізація з використанням тільки `numpy` (без `scikit-learn`)
- Формула: `θ = (X^T X)^(-1) X^T y`
- **Результат:**
  - Коефіцієнти моделі: `[intercept, slope]`
  - RMSE: ~4662

#### 2️⃣ Full-Batch градієнтний спуск
- Реалізація з `numpy` з використанням нормалізованих даних
- Протестовано 3 різних learning rate: `0.001, 0.01, 0.05`
- **Найкращий learning rate:** 0.01
- Побудовано графік зміни RMSE залежно від ітерації
- **Результат:**
  - Коефіцієнти близькі до МНК
  - RMSE: ~4662

#### 3️⃣ Scikit-learn LinearRegression
- Використання готової імплементації з `sklearn.linear_model`
- **Результат:**
  - Коефіцієнти: slope ≈ 267, intercept ≈ 3165
  - RMSE: ~4662

**Візуалізація:**
- Діаграма розсіювання даних `age` vs `charges`
- Три лінії регресії (МНК, ГС, sklearn) на одному графіку

**✅ Висновки:**
- Усі три методи дали **ідентичні результати** — лінії повністю збігаються
- Коефіцієнти майже не відрізняються між методами
- RMSE приблизно 4662 для всіх моделей
- Кожен рік віку збільшує медичні витрати приблизно на **267 одиниць**
- Це підтверджує правильність реалізації всіх методів

---

### 🔹 Завдання 2: Лінійна регресія для курців

**Мета:** Оцінити, наскільки добре лінійна модель за віком прогнозує медичні витрати для курців.

**Реалізація:**
- Використано `sklearn.linear_model.LinearRegression`
- Навчання на підмножині даних курців (`smoker == 'yes'`)

**Результати:**
- **Коефіцієнти:**
  - Slope (нахил): ~280-290
  - Intercept (зміщення): ~18000-20000
- **Метрики якості:**
  - RMSE: значно вищий, ніж для некурців
  - R² score: **≈ 0.16** (дуже низький показник)

**Візуалізація:**
- Діаграма розсіювання з лінією регресії
- Видно високий розкид точок навколо лінії

**❌ Висновки:**
- Модель **не є достатньо точною** для використання в компанії
- Вік пояснює лише **16% варіації** медичних витрат для курців
- Велика частина варіації залежить від інших факторів:
  - Індекс маси тіла (BMI)
  - Кількість дітей
  - Регіон проживання
  - Стаж куріння та інтенсивність
- **Рекомендація:** Потрібна багатофакторна регресія з додатковими ознаками
